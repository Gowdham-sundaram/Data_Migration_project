How to use this review and understand the profile
  1. Select a delimited text file with a header row, or load the clearly fictional sample. Your file stays in this browser tab.
  2. Review discovered columns and profiling hints. These metrics help you spot patterns; they are not business rules.
  3. Map each source field to a target column name. Names stay unchanged by default. Choose an explicit text, date, number, currency, or split operation where needed.
  4. Optionally combine two source fields into a new target field. Then set required/type/allowed-value/unique checks against the target columns, based on approved customer requirements.
  5. Inspect the transformed Ready and Needs review previews. Invalid conversions are flagged; rows are not silently deleted or deduplicated.
  6. Confirm you reviewed the Ready preview, approve, then download its CSV. Any mapping, transform, or rule change clears approval. Resolve review rows from the separate local review download.

How useful are profiling and transformations? Profiling provides first-pass hints; explicit mapping operations produce a customer-defined output shape and checks can catch configured issues. Data Migration Helper does not understand business requirements or decide the correct mappings, allowed values, or formats for you. Have a data owner confirm these settings. A repeated value in one column is not necessarily a duplicate record, and this prototype does not replace a full schema-aware assessment.
